# EDA Research: Каталог экзопланет NASA

Данный репозиторий содержит проект по разведочному анализу данных (Exploratory Data Analysis, EDA), посвященный исследованию подтвержденных экзопланет.

## Описание проекта
В качестве источника данных используется каталог **NASA Exoplanet Archive (Planetary Systems Composite Parameters)**. Цель работы — исследовать физические характеристики планет (радиус, масса, орбитальный период) и проверить, как методы их обнаружения влияют на формирование наблюдаемой выборки. 

В ходе анализа проверялись три исследовательские гипотезы:
*   **H1 (Размер планет):** Транзитный метод имеет наблюдательное смещение в сторону планет с меньшим радиусом по сравнению с методом лучевых скоростей (`Radial Velocity`).
*   **H2 (Орбитальный период):** Транзитный метод фиксирует более короткие орбитальные периоды. Предполагается, что это связано с геометрией наблюдений, а не с реальным различием в распределении планет во Вселенной.
*   **H3 (Связь с родительской звездой):** Существует корреляция между радиусом планеты и эффективной температурой её звезды.

## Ключевые выводы
Анализ выявил значительное расхождение медианных значений в зависимости от метода обнаружения. Транзитный метод фиксирует в основном компактные планеты с короткими периодами (медиана 2.46 R⊕ и 8 суток), тогда как метод лучевых скоростей смещен в сторону более массивных объектов с длинными орбитами (12.6 R⊕ и 307 суток). Это наглядно демонстрирует **эффект наблюдательной селекции** — каталог отражает не реальную популяцию планет, а ограничения возможностей телескопов.

Также было установлено, что связь между радиусом планеты и температурой её звезды крайне слабая (коэффициент Спирмена ~0.196). Температура звезды не является надежным предиктором размера планеты.

## Структура репозитория
*   `NASA_Exoplanets_EDA.ipynb` — основной Jupyter Notebook с кодом, визуализациями и подробными выводами.
*   `exoplanets.csv` — исходный датасет, использованный для анализа.

## Используемые инструменты
*   **Python** (Pandas, NumPy) — обработка и анализ данных.
*   **Matplotlib, Seaborn** — визуализация данных.
